# MakeUp Ultra Fast — Horizon Rust Edition

**Bringing the popular MakeUp Ultra Fast shader to Minecraft Java Edition rewritten in Rust (Horizon).**

This project is an unofficial conversion of **MakeUp Ultra Fast** for the Rust-based Minecraft project, Horizon.

The goal is to bring MakeUp's visual enhancements to Horizon while preserving its original visual style and performance-focused design.

## ✨ About

MakeUp Ultra Fast is known for its balance between visual quality and performance. This project aims to make those visuals available in Horizon, allowing players to experience enhanced lighting and graphics in the Rust-based Minecraft implementation.

### Original shader features

Depending on conversion compatibility, the original shader includes:

- Dynamic shadows
- Volumetric clouds
- Temporal anti-aliasing (TAA)
- Enhanced ambient occlusion
- Water reflections and refractions
- Depth of field
- Motion blur
- Bloom
- Chromatic aberration
- Auto exposure
- Customizable visual effects

**Note:** Not all original effects are necessarily supported by the Horizon conversion.

## 🦀 Built for Horizon

This project targets **Horizon**, the Rust rewrite of Minecraft: Java Edition.

The conversion uses Horizon Translator to help adapt conventional Minecraft shaders for Horizon's rendering environment.
